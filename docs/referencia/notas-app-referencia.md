## CONCLUSÕES

### Mapa de telas (5 abas)
Home | Alunos | (+) | Treinos | Progressão   + drawer lateral de configurações

### Modelo de dados implícito
Professor (admin)
 └ Aluno (foto, email, desde, status, gênero, anamnese, restrições de saúde)
    ├ Assinatura (plano, valor, vencimento, recorrente, congelar/cancelar/trocar)
    ├ Avaliações (Inicial/anamnese, Física/medidas, Endurance/zonas, Corporal/fotos)
    └ Programa de treino (ativo/inativo, biblioteca de modelos)
       └ Sessão (letra A-E, nome, dias da semana, duração estimada)
          └ Exercício (ordem, séries, reps, descanso, RIR, finalização opcional)
             └ Série registrada (carga, reps) -> alimenta volume, 1RM, ACWR, PSE

### Motores automáticos ("Ion" / "Engine")
- Musculação: objetivo + periodização + nível + frequência + divisão + ênfase -> gera mesociclo
- Endurance: modalidade + prova + periodização + km inicial/pico + progressão + dias -> gera plano
- Varredura da anamnese sugere restrições clínicas, mas exige confirmação do profissional

### Métricas calculadas
volume (kg = séries x reps x carga), séries/semana por grupo muscular, 1RM Epley,
ACWR (aguda 7d / crônica 28d), PSE média/máx/mín, streak, frequência

### Identidade visual
- Fundo #F2F3F5, cards brancos raio ~18px, sombra suave
- Texto escuro azulado, secundário cinza
- Cores: verde (ativo/sucesso), roxo (histórico/avaliação), azul (info/cluster),
  laranja (alerta/revisar), vermelho (cancelar), rosa (aniversário/foto)
- Tiles com gradiente nas ações rápidas
- Pills de status, badges numéricos, títulos com barrinha vertical colorida
- Tab bar 5 itens com botão central circular "+"

### OBSERVAÇÃO IMPORTANTE
"Sangoleti Pro" + logo NS = provavelmente um SaaS white-label já assinado pela Naiara
(ela aparece como "admin" com a própria marca). Ou seja: é um produto comercial pronto,
não um app dela. Recriar = projeto grande.
